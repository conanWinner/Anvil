## Quick reference

The essentials at a glance:

- **Primary gradient** — <code style="color:#ED10EC">#ED10EC</code> → <code style="color:#8E40C8">#8E40C8</code> → <code style="color:#06CE94">#06CE94</code>
- **Surface** — <code style="color:#0F1115;background:#fff;padding:0 6px;border-radius:3px">#0F1115</code>
- **Logo** — the shield mark with the abstract Anvil glyph, stroked with the primary gradient

### System 3 surface

The System 3 project screens (`/console/projects`) use their own light surface, scoped to `.system3-root` and defined in `packages/web/src/features/system3/system3-theme.css`. It does not replace the brand palette elsewhere; dark mode keeps the standard dark surface.

- **Background / surface** — <code>#F6F4EF</code> (warm ivory) · <code>#FBFAF7</code> cards · <code>#F3F0E9</code> muted · <code>#EEF5F0</code> soft green
- **Lines** — <code>#E4DFD4</code> · <code>#D9D3C6</code> strong
- **Text** — <code>#2B2A27</code> · <code>#5F5A51</code> muted · <code>#6B665D</code> subtle
- **Accent** — <code style="color:#1D6B4F">#1D6B4F</code> green (primary actions, running and passed states) · <code style="color:#2F7D63">#2F7D63</code> secondary
- **Status** — <code style="color:#A15C07">#A15C07</code> warning · <code style="color:#A3321F">#A3321F</code> error
- **Type** — JetBrains Mono for titles, labels, navigation and numbers; Inter for prose. Boxed uppercase badges for status.

Use the embedded foundation below for the canonical version. If you need a vector asset or have a question about an unusual usage, open a discussion on [GitHub](https://github.com/conanWinner/Anvil/discussions).
